# 3D 麻將塔（Mahjong Solitaire）

用 Three.js 打造的 3D 麻將配對遊戲：找出兩張相同且「可移動」的牌，點擊即可消除。

## 玩法
- **可移動的牌**：上方沒有被其他牌壓住，且左側或右側至少一邊是空的。被擋住的牌會略為變暗。
- 花牌（梅蘭菊竹）彼此可配對，季節牌（春夏秋冬）彼此可配對。
- 4 秒內連續配對會觸發**連擊**加分；清空整盤依用時給予時間獎勵。
- 每局發牌都保證**有解**；洗牌也會重新產生有解的排列。

| 按鈕 / 快捷鍵 | 功能 |
|---|---|
| 💡 提示 `H` | 標示一組可消除的牌（-5 分） |
| ↶ 悔棋 `Z` | 復原上一組 |
| 🔀 洗牌 `S` | 重排剩餘牌（-20 分） |
| 🀄 新局 `N` | 選擇牌陣重新開始 |
| 🔊 / 🎵 `M` | 音效 / 古箏風背景音樂開關 |

滑鼠拖曳旋轉視角、滾輪縮放；手機可觸控操作。

## 牌陣
經典烏龜（144）、金字塔（120）、城堡（106）、入門（36）

## 技術
- **3D**：Three.js r160（圓角牌體、翡翠牌底、PBR 光澤、軟陰影、環境反射、粒子特效）
- **牌面**：Canvas 程序繪製萬／筒／條／字牌／花牌
- **音效**：Web Audio API 即時合成（木質敲擊、編鐘和弦、五聲音階撥弦音樂），無需音檔
- **美術**：背景與牌背由 H站（Higgsfield, GPT Image 2）生成，詳見 `assets/README.md`

## 執行
ES modules 需經由 HTTP 伺服器開啟：

```bash
python3 -m http.server 8000
# 瀏覽器開啟 http://localhost:8000
```

也可直接部署到 GitHub Pages / Netlify / Vercel 等靜態網站空間。
